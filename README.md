# 10th DGK Board Marks Scraper 🎓

A Python tool designed to scrape and extract student marks data from the 10th Class DG Khan (DGK) 2026 Board results into clean, structured files. This is just what I made before i knew gazette's existed. I do not recommend running this at all! each dataextraction.py extracts a certain amount e.g 10k or 20k roll numbers. 

---

## 🛠️ Getting Started

### Step 1: Install Dependencies
Install all required Python libraries using the `requirements.txt` file:

```bash
pip install -r requirements.txt
```

### Step 2: Run the Extraction Script
Execute the data extraction script to start scraping:

```bash
python dataextraction1.py
```

---

## 📦 Output Data

Once the script completes, your extracted data will be cleanly organized and saved into **4 separate output files** in the project directory.
